# 抖音公开页面链路调查

本轮记录：2026-10-27（Asia/Shanghai）。实验性标识保留。本文件不包含用户分享文案、完整分享链接、签名媒体直链、Cookie 或密钥。

## 本轮实际观察

检查对象为官方账号的一条公开历史视频，以及官方品牌账号一条索引描述含“点击图片”的图文候选。候选是否确为图集尚未从平台媒体数据确认，因此不把它记为已通过真实图集解析。样本在本机证据中仅使用标签与来源散列标识。

| 阶段                             | 实际结果                                                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 分享文案提取、官方域名与逐跳限制 | 现有逻辑及本轮单元测试覆盖；本轮使用具体作品地址，没有取得可供验证的官方短链，真实短链跳转仍未执行                               |
| 本机读取公开视频页面             | HTTP 200，`text/html`，72,914 字节；没有可见正文、目标作品 ID 或已支持的 hydration 数据块                                        |
| 本机读取图文候选页面             | 同样为 HTTP 200、72,914 字节；HTML SHA256 与视频页面相同，没有目标作品 ID 或公开媒体数据                                         |
| 页面脚本观察                     | 两个 script，含 `document.cookie`、`window.location`、`__ac_` 与 `byted_acrawler` 标记；只观察文本，没有执行、仿造或逆向验证脚本 |
| 默认生产域名解析                 | 两个样本本轮均返回 HTTP 422，无媒体结果；约 0.96～2.66 秒                                                                        |
| Cloudflare 域名解析              | 首次视频请求返回 HTTP 422；随后本机代理连接出现 `UND_ERR_CONNECT_TIMEOUT`，不能把后者写成平台解析器失败                          |
| 媒体匹配与直链                   | 页面没有目标数据，未取得可确认的媒体直链                                                                                         |
| 浏览器媒体下载与打开             | 无媒体对象，未执行；没有真实下载成功证据                                                                                         |

两个不同作品返回完全相同、没有作品数据的脚本页面，说明本轮收到的内容不是可直接解析的作品详情。脚本标记提示可能存在客户端校验或脚本依赖，但没有可见登录提示或验证码页面；不能据此断言具体是登录、验证码、内容删除还是平台风控。

这与 HTTP 200 的区别有关：成功取到一个 HTML 响应，不等于响应含目标作品。继续增加 JSON 字段别名不能从无作品数据的响应中制造可用媒体。当前不通过增加登录 Cookie、执行验证脚本、购买接口或媒体中转改变边界。

本机脱敏证据：`F:\轻匣\logs\douyin-investigation-current.json`。其中仅保存响应类型、字节数、数据块/脚本标记、目标 ID 是否存在、页面散列和阶段结果，没有保存原始 HTML 或签名直链。此前 `douyin-validation.*` 为上线阶段的历史证据，未覆盖。

## 已实现的必要改进

1. 解析错误带稳定的 `code` 与 `stage`，区分输入、跳转、平台页面和媒体数据阶段。保留安全的中文错误，不回传底层请求 URL 或异常详情。
2. 区分真实 404/410、平台限频、非 HTML、空响应、超大页面、超时和网络失败；有效作品地址遇到上游失败时不再统一标为用户输入 400。
3. 仅在公开可见文字明确显示时提示登录或验证；没有作品数据的 JavaScript 壳页面使用 `PUBLIC_DATA_UNAVAILABLE`，不冒充已确认的平台登录或验证码原因。
4. 账号主页、搜索页在请求上游前拒绝。短链跳转后没有可确认的作品 ID 时不取第一个推荐作品；已知 ID 不匹配时也不返回其他作品。
5. 下载取消与超时有明确中文提示，保持不保存不完整文件。浏览器 `TypeError` 提示跨域、防盗链或网络等可能原因，不直接断言一定是 CORS。下载期间禁止启动另一轮解析。

没有添加第三方接口、登录流程、媒体代理、媒体存储、平台搜索或批量抓取。
