# 抖音公开链路实测记录（2026-10-27）

本记录只包含非秘密的实测结论。用户提供了有权下载的自有公开视频分享链接；原始分享文案、链接、作品编号、签名媒体直链、页面正文、Cookie 均不写入本报告或 Git。测试样本标记为 `user-owned-feedback-test`。

## 已执行并验证

- 匿名访问原短链，逐跳验证官方域名，实测 `v.douyin.com` 返回 302，`www.iesdouyin.com` 返回 200。未携带登录 Cookie、未执行页面脚本、未生成或改写平台签名。
- 普通 `www.douyin.com/video/…` 页面在本次匿名 HTTP 条件下是 200 JavaScript 壳。移动分享页虽有 `_ROUTER_DATA` 和目标编号，但目标节点只有页面配置，未包含可用媒体。HTTP 200 不能证明解析成功。
- 同一目标的官方 `jingxuan.douyin.com/m/video/…` 页面包含 `window._SSR_DATA`。只读取 `data.storeState.detail.videoData.result`，核对其 `gid` 为分享链接揭示的目标；进一步核对 `video_model` 中的 `video_id` 与当前 detail 一致。用户给出的标题关键词匹配。没有读取 `user-page` 内的其他作品列表。
- 目标模型包含 H.264 与 H.265 变体。本次选择原始 H.264 720p 变体的 `backup_url`，保持 URL、签名、路径与质量原样。没有替换水印路径，没有媒体中转。
- 从真实轻匣页面 origin 发起浏览器直接下载，`credentials: omit`、`referrerPolicy: no-referrer`：返回 200 `video/mp4`，完整 **7,518,058 字节**，容器标记 `ftyp`。浏览器下载事件无失败；本地重新读取并解码为 **1280×720、80.042653 秒、readyState 4**。这证明该样本当次的解析、浏览器跨域读取、完整下载及解码均成功。
- 下载测试文件位于仓库外日志目录，SHA-256 为 `024a3245790511c18f85cb8168915ec551ce36c51980f30827324ccb65ba9af8`。不向服务端保存视频。
- 本轮新 `resolveDouyinShare` helper 实测复用同一短链，3 次官方请求完成目标确认，耗时 **1,654 ms**。返回 1 个视频、原始备链优先、同一 H.264 变体的原始主链为备用。所有页面请求明确 `credentials: omit` 且无 Cookie。
- 对 helper 实际返回的媒体首地址做有界 1024 字节 Range 验证，得到 206 `video/mp4` 和 `ftyp`。此 Node Range 请求未带浏览器 Origin，其响应未包含 ACAO，不能单独拿它证明跨域成功；跨域证据来自上述完整浏览器下载。

## 已实现并在本地验证

- 精确添加 `jingxuan.douyin.com` 官方分享 host，沿用每跳 HTTPS、凭据、端口、域名白名单以及独立媒体白名单校验。
- 为原始分享页保留原解析路径。只有目标编号已知、公开页缺少可用媒体时，才访问一次同目标的精选 canonical 页面。明确登录、安全验证、删除、403、429 不触发替代页面尝试；图集、未知目标、已访问精选的页面不重复尝试。
- 原页、跳转与精选请求共享 **18 秒总预算**及 **5 次页面请求上限**；每次页面请求至多 7 秒、HTML 至多 4,000,000 字节。
- 精选仅解析受限 JSON，不执行 JS；只支持已取得真实证据的 H.264 `video_list` 结构。目标编号或内部视频编号不符、模型无效、非允许媒体域、任意 base64 字符串均拒绝。
- 返回可选 `item.fallbackUrls`，只包含同一变体内经过校验、有序去重的原始 URL。客户端包括首地址在内最多尝试 2 个；旧响应保持兼容。接口仍标记 `experimental: true`，仅解析成功不等于浏览器下载成功。
- 客户端从分享文案中本地提取 HTTPS URL，只向解析接口发送 URL，不发送标题、正文或作者文案。下载直接到平台，忽略凭据及 referrer；网络或 HTTP 失败才尝试该作品的另一个原始地址，共用取消信号和 90 秒超时。
- 保留 200 MB 上限，拒绝非媒体、空文件、声明长度不符及局部文件；206 必须有可读且证明完整的 Content-Range，否则不保存。取消时不继续备用请求、不保存部分结果。
- 精选备用页不存在或显示删除不证明原分享作品删除，使用单独的 `PUBLIC_DETAIL_UNAVAILABLE`；原分享页真实 404/410 仍保留原含义。
- 脱敏合成夹具覆盖真实 SSR 层级、推荐内容误取、内部编号错配、非法媒体地址、显式访问限制、共享 deadline、共享跳转请求上限及 API 不读取媒体正文。`tests/douyin.test.ts` **72/72 通过**；全部逻辑、安全、数据库与下载单元测试 **189/189 通过**。
- 生产构建通过；整站浏览器回归 **39/39 通过**，包含真实生成并下载后解码的媒体备选链测试、取消与不保存部分文件、URL-only 请求断言，以及已有图片/PDF/音视频实际输出、隐私、收藏、最近使用、主题与动效降级。早期新下载夹具冷编码器尚未输出帧就固定停录的失败已定位；改为真实编码数据驱动结束，并保留字节一致及 `loadeddata` 解码断言后，全套通过。
