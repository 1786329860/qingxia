# 首页标题字体

`qingxia-heading-subset.ttf`：Noto Serif SC，500 字重，使用 Google Fonts 官方 text 子集接口，仅含首页品牌标题“把日常小事，轻轻解决。”所需字符，5,300 bytes。SIL Open Font License 1.1 见同目录 `OFL-NotoSerifSC.txt`。

来源：Google Fonts `Noto Serif SC`（google/fonts 的 `ofl/notoserifsc`），2026-10-27 获取。官方子集接口返回的文件未修改字形；站点本地部署，不向 Google/CDN 发送访客字体请求。源文件字体名保持不变；CSS 别名 `Qingxia Song` 只用于选取本地子集，其他文字沿用系统字体。
