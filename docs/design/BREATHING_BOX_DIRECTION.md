# 会呼吸的数字匣子 · 方向约定

用户已委托设计取舍，本轮直接制作代码原型；不再进行风格选择问答。产品事实见 PRODUCT.md，原视觉/性能基线在仓库外 logs/visual-upgrade-20261027。保留墨绿、荧光浅绿和立方体。

## 比较与选择

比较三个可实施构图：①中央展台，文字绕玻璃匣子排布；②暗室里的侧向光匣，左文字与搜索、右独立材质场景；③悬浮工具抽屉，以卡片堆叠成为主视觉。选②：既有清楚的输入区，也容纳有体积感的品牌对象；①搜索路径过于绕行，③容易让装饰工具与真实入口混淆。自动对照服务降级无外部挑战板；沿用户指定方向，不声称完成了外部评选。

## 第一视口与路径

首页是数字工作空间（Operate）。左侧中文两行标题“把日常小事，轻轻解决”，第二行以自托管宋体字形引入细腻笔画；一段真正可读的说明，紧接实际搜索。右侧玻璃匣子承受单一侧光，内部柔光与薄盖形成层次。工具列表在首屏下沿进入，留有安静的密度变化。手机把文字与搜索放前、匣子单独居中，无装饰压字。

## 统一规则

- 暗色：近黑森林底、暖白正文、荧光浅绿；浅色：矿物白底、墨绿正文、翡翠冰玻璃，不套深色滤镜。
- 背景保持干净，主视觉有空间/折射，工具区域以精确边线和实体表面承载任务，不到处使用模糊玻璃。
- 中文标题桌面 40–64px，移动 31–43px；卡片正文 14px、标题桌面 17px/移动 18px；导航 13px，计数、图注等辅助信息 9–12px，操作正文不靠微小字号制造精致。数字采用等宽数字。
- 导航/卡片/路由/反馈主节奏 240ms，进度 180ms、侧栏 320ms、主题图标 420ms；通用按钮沿用 150ms。交互统一 cubic-bezier(.2,.8,.2,1)。内容默认可见，路由只作轻微位移/明度反馈，无离场等待。工具任务身份不按主题或动效重新创建。
- 只有首页场景持续呼吸/轨道微光；30fps 绘制上限，场景隐藏或离开视口暂停，低能力/省流/减少动态用完整静态材质。
- 卡片 hover 轻抬与边缘光，focus-visible 同等清楚；收藏用按压与心形填充反馈、aria-live 状态；不用动态光标或滚轮接管。
