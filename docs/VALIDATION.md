## 自动化验证

- `npm test`：123 个测试，覆盖文本编码/CSV安全、精确换算、页码范围、随机与颜色、媒体时间规划、ZIP重名不丢文件、抖音解析与域名防护、管理员权限及统计输入。
- 数据库测试使用 PGlite 的真实 PostgreSQL WASM 引擎执行迁移，验证可重复运行、RLS访问隔离、北京时间日/小时聚合、日UV、处理成功/失败、数据库共享限流和90天清理。这不等于连接或验证了你的外部 Supabase 项目。
- `npm run test:e2e`：站点导航、搜索/收藏/最近使用、22路由、JSON完整下载、后台访问保护与示例图表、移动布局，以及图片/PDF/媒体真实输出。完整集成测试共14项。
- 浏览器图片测试验证 AVIF 文件容器与重新解码、WebP ZIP 和不上传输入文件。
- PDF 浏览器测试重新读取输出文件，核对合并顺序、页数、拆分页码、PNG像素和图片转PDF方向。
- 媒体浏览器测试由浏览器生成带音轨的 WebM，再抽帧 ZIP、生成 GIF、提取 MP3/WAV；检查真实文件签名、可解码性、尺寸与音轨时长。
- `npm run build`：TypeScript 与 Vite 生产构建；FFmpeg、PDF字体与许可资源随站部署。
- 清空依赖后按锁文件重新安装与构建已通过；同样的14项浏览器集成测试也在实际 `dist` 生产预览中全部通过，确认打包后的Worker、AVIF、PDF字体与FFmpeg资源路径可用。
- 生产依赖 `npm audit --omit=dev` 在本次检查未报告已知漏洞；该结果会随数据库与版本变化，不是永久保证。

## 手动/补充验证

已经在当前云实例的 Chromium 中验证图片 PNG/JPG/WebP/AVIF互转、强制本地WASM AVIF解码、透明度、取消操作；PDF压缩的保留文字与图片化模式；二维码真实PNG、标准SHA256、随机UUID规范位、非法输入提示。

桌面1440px、手机390px与320px检查页面布局。深浅主题、键盘搜索、移动抽屉与减少动态效果偏好已实现。其他浏览器与真实手机仍需实际设备验收，不将Chromium结果宣称为所有浏览器均已通过。

## 文件与隐私边界

浏览器功能测试检查本地工具的POST请求，只允许匿名事件字段，不包含文件内容或输入正文。链接解析属于单独标注的联网工具，会发送用户主动粘贴的URL。浏览器下载媒体时直接访问平台，不经过本站媒体中转服务器。

关于工具和格式的详细限制，见每个工具页面。重要文件请保留原件；数字签名、嵌入字体、特殊表单、超大图片、超长视频与不完整录屏文件应单独检查处理结果。
